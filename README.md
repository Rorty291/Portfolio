## Опис
Основна задача цього портфоліо - демонстрація навичків, які я здобув протягом навчального курсу з предмету Інструментальні засоби програмування.

## Що я дізнався в процесі виконання
Навчився створювати структуру для сайтів, використовувати посторонні фреймворки та стилі.

## Кроки для повторення проэкту
* Створення репозиторію.
* Змінненя структури сайту `index.html`.
* Додавання файлу стилю `style.css`.
* Додати картинки у папку `assets`.
* Використання фреймворку Bootstrap.
